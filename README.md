# Warehouse Packing App

Отдельное Windows-приложение для упаковщиков.

Идея:
- менеджеры работают в веб-панели `/warehouse`;
- упаковщики запускают это приложение на ПК с принтером;
- печать ШК и PDF выполняется локально, без браузерных ограничений и сетевого доступа сервера к ПК упаковщика.

## MVP

- Получить список назначенных FBO-заданий с сервера.
- Открыть карточку задания.
- Создавать грузоместа: паллеты или короба.
- Вносить состав: SKU, количество, срок годности.
- Печатать штрихкоды локально.
- Скачивать и печатать PDF-этикетки Ozon локально.
- Искать товары в номенклатуре сервера и печатать их штрихкоды.
- **Упаковка FBS (Яндекс):** пик товара → печать ярлыка заказа → пик ярлыка; ручная сборка с ШК на экране.

## Настройка

1. Установить Python 3.11+.
2. Создать окружение:

```bat
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
```

3. Скопировать конфиг (опционально — адрес сервера и печать можно задать в настройках приложения):

```bat
copy config.env.example config.env
```

4. На сервере должны работать **два** процесса:
   - `python run_web.py` — веб-панель (задачи, каталог), обычно `:8765`
   - `python run_api.py` — API упаковщиков (FBS), обычно `:8766`

5. Запуск:

```bat
start.bat
```

6. При открытии ввести адрес сервера (веб), при необходимости адрес API, логин и пароль от панели склада.

## Упаковка FBS

1. В панели `/warehouse` → FBS → Яндекс создайте задание и назначьте себя упаковщиком.
2. В приложении откройте вкладку **«Упаковка FBS»** → задание.
3. Обычный режим: сканер в поле «Сканер» → пик ШК товара → печатается ярлык → пик ШК с ярлыка заказа.
4. Нет ШК на штуке: включите **«Ручная сборка»**, возьмите строку тапом или снимите ШК с экрана.
5. Пока строка активна: **Перепечатать** / **Закрыть без скана** / **Отменить печать**.


## Сборка exe

Позже можно собрать:

```bat
pyinstaller --onefile --noconsole run.py
```

## Авторизация

Используется тот же логин и пароль, что и для веб-панели `/warehouse`. После входа cookie-сессия хранится в памяти приложения до его закрытия.
